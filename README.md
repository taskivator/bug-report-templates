# Bug report templates

Free bug report templates for Jira, GitHub Issues and Azure DevOps, a steps to reproduce checklist and a severity and priority guide. Copy them, adapt them and share them with your team.

Made by the team behind [BugIt](https://bugit.dev/). The same templates, with a copy button for each, are at [bugit.dev/templates](https://bugit.dev/templates/).

A template is the manual way: you fill in each box yourself. [BugIt](https://bugit.dev/) does the filling in for you. From a rough note it writes the whole report in your team's house style, reads your glossary, searches your tracker for duplicates, checks that the steps, expected and actual results and build are there, and files it when you type FILE IT.

## What is here

| File | What it is |
|---|---|
| [bug-report-template.md](bug-report-template.md) | A general bug report template with a place for each fact a developer asks for first. |
| [jira-bug-report-template.txt](jira-bug-report-template.txt) | The same layout as plain text that pastes cleanly into a Jira description. |
| [.github/ISSUE_TEMPLATE/bug_report.yml](.github/ISSUE_TEMPLATE/bug_report.yml) | A GitHub issue form. Copy it to the same path in your repository and new bug reports get labelled boxes. |
| [azure-devops-bug-template.txt](azure-devops-bug-template.txt) | What goes in each field of an Azure DevOps bug, from Title to Related. |
| [steps-to-reproduce-checklist.md](steps-to-reproduce-checklist.md) | A checklist for steps a stranger can follow, with a template to paste. |
| [severity-and-priority-guide.md](severity-and-priority-guide.md) | Severity and priority scales you can copy, examples of each combination, and a rule for disagreements. |

This repository uses the issue form itself, so you can see it working on the [new issue](../../issues/new/choose) page.
